# Рисование карты

Всё, что рисует `MapPainter` — в `src/render/painter/layers/*.js`. Здесь разобрано по слоям (в порядке
отрисовки), с пояснениями и точками настройки.

## Общие понятия

- **Один холст, пиксель за пикселем.** `paint()` создаёт `ImageData`, оборачивает его в `Int32Array` `pixels`
  и все слои пишут цвета прямо в него. В конце `putImageData` выводит результат на канвас.
- **Цвет — это одно число** (`0xAABBGGRR`, как в `Int32Array`). Смешение/осветление/затемнение —
  функции из `src/render/color.js` (`mixPacked`, `shadePacked`, `speckColor`). Они целочисленные и очень
  быстрые: вызываются миллионы раз.
- **`px(n)`** переводит «пиксели для клетки 16×16» в текущий `tileSize`. Пример: `px(8)` при клетке 16 — это
  8 пикселей, при клетке 24 — 12. Все размеры рисунков задавайте через `px()`, тогда карту можно масштабировать.
- **`waterMask`** — массив размером в пиксели: 1 там, где нарисована вода. Его заполняет `paintBase`, а
  используют другие слои (берега, реки, чтобы не рисовать на воде).
- **`put(x, y, color)`** ставит пиксель с проверкой границ; **`rect(x, y, w, h, color)`** — прямоугольник;
  **`linePoints(x0, y0, x1, y1)`** — пиксели отрезка (алгоритм Брезенхэма); **`blend(x, y, color, a)`** —
  смешивает цвет с уже нарисованным.

## Порядок слоёв в `paint()`

```js
this.paintBase();          // 1. цвет каждой клетки + дизеринг границ
this.roundCoastCorners();  // 2. скругление углов побережья
this.buildReliefHeights(); //    карта высот гор
this.paintHills();         // 3. тени холмов и впадин
this.paintShores();        // 4. пляжи, галька, утёсы
this.paintRivers();        // 5. реки и их кромка; броды (в paintScene)
this.paintRoads();         // 6. дороги
this.paintSettlementGround();
this.paintTexture();       // 7. крапинки, волны, цветы, листва
this.paintRegionBorders(); // 8. границы регионов (если включены)
this.paintScene();         // 9. декорации снизу вверх: деревья, дома, руда, кости
this.applyGrading();       // 10. тёмный стиль: цветокоррекция, туман, виньетка
this.emissive.forEach(fn => fn()); // 11. источники света поверх цветокоррекции
```

## 1. Фон и дизеринг — `base.js`, `tile-colors.js`, `coast.js`

### `tile-colors.js`

- `buildTileColors()` — для каждой клетки считает её базовый цвет (`tileColor`) из биома/сезона, с учётом
  снега (`snowCoverage`, порог `SNOW_TEMPERATURE`), близости реки (`nearRiver`), плодородия
  (`fertilityTint`).
- `waterColor(i)` — цвет воды по глубине (`waterShadeIndex`, ступени `WATER_DEPTH_STEPS`).
- `groundColor`/`shadeStep` — вспомогательные.

### `base.js`

- `paintBase()` — заполняет каждый пиксель цветом своей клетки. Границы между разными клетками
  **дизеринг**: `blendGrid()`/`blendChoices()` берут цвета соседей и через порог Байера (`BAYER`) выбирают,
  какой цвет поставить в переходном пикселе. `blendSharpness` задаёт резкость перехода (больше — резче).
  Слой записывает `tileColors`/`tileWater` — ими пользуется скругление берега.

### Скругление берега — `coast.js`

Вся работа с береговой линией собрана в одном модуле `src/render/painter/layers/coast.js`.

1. `roundCoastCorners()` идёт по клеткам-суше. У каждой проверяет четыре диагональных соседа: если по
   диагонали вода, а по ортогонали суша — это «выступающий» угол, и он подрезается.
2. Подрезка — четверть круга радиусом ~0.45 клетки: пиксели угла получают цвет воды из диагонального
   соседа. Квадрат превращается в восьмиугольник с округлыми углами; берег перестаёт идти ступеньками.
3. Тело клетки не меняется (срезается меньше половины площади), поэтому при наведении тип клетки совпадает
   с рисунком; `waterMask` обновляется вместе с пикселями.

Радиус задан долей клетки, поэтому форма углов **одинакова** при любом `tileSize`.

> Границы пляж/галька/утёс (`shores.js`) идут вдоль берега по близости клеток берега к пикселю
> (`shoreTypeAt`) — поэтому полосы мягкие, а не строго по границам клеток.

## 2. Горы и холмы — `relief.js`, `hill-shading.js`, `hills.js`

- `buildReliefHeights()` строит карту высот для рисования гор: по `mountainHeight[i]` (`relief.js`),
  `mountainLift` — насколько высоко самые высокие горы поднимаются вверх (к северу), `peakSharpness`
  (`addPeaks`) — округлые холмы (0) или острые пики и гребни (1). Высоты размываются (`blurMountainHeights`),
  чтобы горы плавно переходили в землю.
- `tilesNearRelief()`, `snowLevel()`, `liftAtTile()` — вспомогательные (снег на вершинах, подъём у клетки).
- `hill-shading.js` — освещение склонов (солнце с северо-запада): по градиенту высоты выбирается ступень
  светотени `STEP_AMOUNTS`.
- `hills.js` — `paintHills()` рисует холмы и впадины на равнинах, `hillStrength` (0 — выключить).

> **Горы.** Меняете их «характер»: `peakSharpness` (острота), `mountainLift` (высота), `hillStrength`
> (холмы). Сам рельеф (где горы) задаётся генератором — `mountainShare`, `mountainClustering` в
> [map-generation.md](map-generation.md).

---

## 3. Берега — `shores.js`

- `paintShores()` — пляжи, галька, утёсы. Идёт **волной от воды вглубь суши**: находит пиксели суши у воды,
  затем распространяет полосу на `reach` пикселей (зависит от `coastSharpness`). Дальше от воды — реже
  (затухание по расстоянию).
- `shoreTypeAt(gx, gy)` — тип берега (пляж/галька/утёс) в конкретном пикселе. Берётся **из сглаженного поля
  воды**, а не из клетки: поэтому граница «пляж/галька» идёт вдоль скруглённого берега, а не по границам
  клеток. Утёсы (`CLIFF`) имеют приоритет над галькой, галька — над пляжем.
- `paintCliffs()` — утёсы: под южным краем суши рисуется каменная «стенка», под ней тень на воде. Край
  обрыва тоже берётся через `shoreTypeAt()`, поэтому обрыв повторяет скруглённый берег.

Сами типы берегов назначает генератор (`classifyShores`, `beachShare`, `cliffShare`).

## 4. Реки и мосты — `rivers.js`

### `paintRivers()` + `buildRiverGeometry()`

1. Строится **маска реки** (`riverMask`): в каждом пикселе уровень реки (1..3) или 0. Русло рисуется по
   `river[i]`/`riverFlow[i]`/`riverTo[i]` с извилинами.
2. Кромка растушёвывается дизерингом: у края (`distance`) цвет реже, к центру — сплошной. `coastSharpness`
   задаёт ширину кромки.
3. `riverWidthAt(i)` / `riverWidth(level)` — ширина в пикселях по потоку воды.
4. Мёртвая/эфирная земля и холод влияют: замёрзшие реки (`RIVER_ICE_TEMPERATURE`) покрываются льдом.
5. `paintBankPixel()` — берег реки: у пляжа песок, у камня галька, иначе тёмная мокрая земля.

### Мосты и броды

Данные переправы ставит генератор (`placeRiverCrossings`: `crossing[i]` = 1 брод / 2 мост). Рисует её
`paintCrossing()` (вызывается из `paintScene` для клеток с `crossing[i]`).

Мост всегда **перпендикулярен реке**, включая диагональные участки и излучины:

1. **Направление течения** в клетке: из `riverTo[i]` (куда течёт) плюс, если есть, из верхней по течению
   клетки (её `riverTo` указывает на нашу). На изгибах это усреднение даёт ось, перпендикулярную самому
   руслу, а не только вектору «вниз».
2. **Ось моста — перпендикуляр** к течению (`(-fy, fx)`).
3. От центра клетки **шагаем вдоль оси** в обе стороны; где кончается вода реки (`riverMask`) — там берег.
   К расстоянию до берега добавляется `bank` (насколько мост заходит на сушу).
4. **Настил рисуется толстой линией** между берегами (`band` — несколько параллельных линий Брезенхэма со
   смещением), краям добавляется светлая кромка. Брод — 2–6 камней вдоль той же оси.

Если `riverMask` ещё нет, ширина берётся из `riverWidthAt(i)`.

> **Что подкрутить.** Толщина настила — `this.px(5)` в `paintCrossing`. Заход на берег — `bank`. Число и
> вид камней брода — блок `else`. Цвет — `colors.bridgeDeck`/`bridgeEdge`/`stone` в
> `src/render/painter/constants.js`.

## 5. Текстура земли — `texture.js`

`paintTexture()` добавляет мелкие детали на равнинах: крапинки (`speckLayout`), пучки травы (`paintTufts`,
`grassDensity`), волны на воде, цветы и листву. Всё — через шум/hash, чтобы рисунок был стабильным для
данного сида. Условия пропуска в начале `paintGroundDetail()` (не рисуем на реке, пляже, поселении, дороге).

---

## 6. Дороги — `roads.js`

`paintRoads()` → `buildRoadGeometry()` рисует дорогу по `roadLevel[i]` и `roadLinks[i]` (биты направлений
`ROAD_DIRECTIONS`). `roadWidth(level)` — ширина по наезженности. Дорога — грунтовая тропа поверх земли.

---

## 7. Декорации — `scene.js`, `props.js`, `vegetation.js`, `settlements.js`, `minerals.js`

`paintScene()` собирает декорации в список `collectDecorations()`, сортирует их по «основанию» (нижней точке)
и рисует **снизу вверх** — так получается перспектива: то, что ближе к зрителю, перекрывает дальнее.

- **Деревья** (`vegetation.js`) — по `resource[i] === WOOD`. `collectTrees`, `drawBroadleaf`
  (широкая крона с рваным краем, прожилками листвы и бликом), `drawConifer` (ярусы с хвоей),
  `drawBareTree`, тени `drawShadow`. Пшеница — `drawWheat`.
- **Дома** (`settlements.js`) — по `resource[i] === SETTLEMENT` и `settlementLevel[i]`.
  `layoutSettlement()` раскладывает домики по клетке; `drawHouse`, `paintSettlementGround`. Домики
  расставлены с разбросом (дрожание), чтобы не выстраиваться в линию.
- **Руда** (`minerals.js`) — золото/железо (`drawOreTile`). **Эфир** — один вид объекта на клетку:
  небольшой кристалл `etherSprite()`/`drawEther()` (примерно вдвое ниже дерева, тень как под деревом,
  в тёмном стиле светится через `emissive`).
- **Атмосфера** (`props.js`) — в тёмном стиле: обугленные пни, осколки, кости, вороны, развалины, виселицы.
  Рисуются на мёртвых землях и пустошах.

---

## 8. Границы регионов — `borders.js`

`paintRegionBorders()` рисует контур региона по перепаду `regionId` между соседними клетками. Включается
флагом `showBorders` (передаётся в `paint()`), не путать с параметрами `options.roads`/`options.shores`.

---

## 8b. Границы фракций — `factions.js`

`paintFactionBorders()` рисует границу там, где соседние клетки принадлежат разным фракциям (`factionId`):
каждая клетка на краю получает обводку **цветом своей фракции** (`colors.factionColors`, тёмная подложка
`factionBorder`). Кромка изрезана крупным шумом и растворяется над водой и реками. Включается флагом
`showFactions`, а в режиме карты «Фракции» вся территория фракции ещё и заливается её цветом
(`tileColor` в `tile-colors.js`).

---

## 9. Стиль dark fantasy — `grading.js`

Для `mood === 'dark'`:

- `applyGrading()` — цветокоррекция (холоднее, темнее), `buildFog()` — туман, виньетка (`vignette`).
- `drawLight()` / `emissive` — источники света (окна домов, костры, эфирные разломы). Рисуются **после**
  цветокоррекции, чтобы оставаться яркими на затемнённом фоне.

Для `mood === 'light'` эти слои пропускаются.

## Палитры и цвета — `seasons.js`, `constants.js`, `color.js`

- `src/render/seasons.js` — палитры для каждого сезона и стиля (`SEASONS` и `DARK_SEASONS`). Палитра — это
  объект с именованными цветами (трава, песок, камень, вода...). `packPalette()` упаковывает её в быстрые
  числа один раз за кадр.
- `src/render/painter/constants.js` — фиксированные цвета (`COLORS`, например `bridgeDeck`, `stone`,
  `wetSand`), пороги (`SNOW_TEMPERATURE`, `ICE_TEMPERATURE`, `RIVER_ICE_TEMPERATURE`), ступени
  (`WATER_DEPTH_STEPS`, `STEP_AMOUNTS`) и матрица Байера `BAYER` для дизеринга.
- `src/render/color.js` — упаковка и операции с цветом.
