# Документация Dark Pixel

Подробные пояснения по коду: как устроена генерация карты, как она рисуется и где что менять.
Документация рассчитана на то, чтобы вы могли править проект самостоятельно, не читая каждый файл целиком.

## Главные идеи в двух словах

- **Данные и картинка разделены.** `MapGenerator` считает «что где находится» и хранит это в плоских
  массивах (`Uint8Array`, `Float32Array`). `MapPainter` только читает эти данные и рисует пиксели.
  Поэтому генерацию можно менять, не трогая рисование, и наоборот.
- **Один большой холст.** Карта рисуется пиксель за пикселем в один `ImageData`, а не спрайтами на канвасе.
  Так получается настоящий pixel art с мягкими «растушёванными» границами биомов (дизеринг).
- **Всё в долях клетки.** Любой рисунок задан относительно размера клетки `tileSize`, поэтому карту можно
  рисовать при клетке 9, 12, 15... пикселей без правок кода. Функция `px(n)` переводит «пиксели для клетки
  12×12» в текущий размер.
- **Слои — это файлы.** Каждый этап генерации (`src/map/steps/*.js`) и каждый слой рисования
  (`src/render/painter/layers/*.js`) — отдельный модуль с методами, которые подмешиваются в прототип класса
  через `Object.assign`.

## Сборка

Исходники — ES-модули в `src/`. Браузер запускает один собранный файл `dist/game.js`:

```bash
npm install
npm run build     # разовая сборка
npm run watch     # пересборка при сохранении
npm run lint      # проверка стиля
```

`dist/game.js` лежит в репозитории, чтобы игра работала без Node. **Не редактируйте его вручную** — он
перезаписывается сборкой.
